About BuffNook Tower

About

An independent game about knowing when to stop.

BuffNook Tower is a free browser game made by a small independent team. We wanted to build something that felt like the physics stacking games we loved as kids — but without the ads, accounts, and friction that clutter the modern web.

What we care about

Three principles that shape everything we build.

01

No accounts, ever

Progress saves in your browser's localStorage. We never ask for an email, a password, or any personal information.

02

No ads, no pop-ups

You play the game, not our marketing. We will never show banner ads, mid-roll ads, or reward-video ads in any game on BuffNook Tower.

03

Desktop and mobile, first class

Every game we ship must work well on a laptop, a phone held one-handed, and a tablet in landscape. No "mobile coming soon".

Tech

Vanilla everything.

BuffNook Tower runs on a Planck.js physics engine inside a single self-contained HTML file. The site itself is plain HTML, CSS, and JavaScript — no frameworks, no build step beyond inlining. We deploy to Cloudflare Pages because it's fast and free for static sites. Source code for the game engine is available on request for educational use.
